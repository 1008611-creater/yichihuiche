# 一期一会 · 看山的人间剧场

知乎黑客松校园新锐季参赛作品 · AI 原生互动叙事 / 情绪治愈游戏。

在线体验：https://1008611-creater.github.io/yichihuiche/

## 玩法

带着一件现实中没能放下的遗憾进入剧场，由引路人带入三段注定以 Bad Ending 收场的陌生人人生。
你无法把任何一段 BE 改成 HE，但你能改变告别的方式、说出口的话、和彼此被理解的程度。

## 技术

- Godot 4.5 导出 Web（WebAssembly）
- 三幕互动叙事 + 自由文本输入 + AI 导演层
- 终章接入知乎真实问答作为「人间镜鉴」

## 运行

直接用任意静态服务器托管本目录即可：

    python -m http.server 8080

或本地打开 `index.html`（部分浏览器需通过服务器访问）。
